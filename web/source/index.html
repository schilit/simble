Both devices are on one page on purpose. Chrome intensively throttles a hidden tab that makes no sound of its own, so a source in a background tab stops feeding its stream within seconds — measured here as 256 SDUs delivered out of 2000. One visible page and one timer removes the problem. The standalone Speaker page is still the one to use when a phone or Bumble is the source.

Handshake

  • Connect to the sink
  • Discover its GATT
  • Configure the ASE
  • Open the CIS
  • Stream
offline

Every step here is real protocol, not a simulation of one: the ASE operations are the bytes ASCS defines, and the stream is established with LE Set CIG Parameters → LE Create CIS → LE Setup ISO Data Path. If the sink is not an LE Audio device, the handshake stops at "Configure the ASE" — there is no control point to write to.
