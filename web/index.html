SimBLE in the browser

SimBLE's Rust Bluetooth stack compiled to WebAssembly, connected to the netsim daemon running on your machine — no backend, no interpreter. Everything below runs the real GATT stack in this tab.

SimBLE Playground build

A free-form Rhai editor — the script is the device. Run it, watch the live GATT viewer, generate any device with AI, and Share a link that encodes your script in the URL. Starts from several examples (heart-rate, battery, a misbehaving device, a test with assert).

API Explorer learn

Fill in an android::* method, press Execute, and it emits one line of Rhai against a live session — teaching the syntax as you build a device click by click. Objects you create (svc1, chr1) become inputs to later calls; copy the whole session out as a script for the Playground.

Color Bulb showcase

A PLAYBULB-style smart light: a Rhai peripheral with a writable [R, G, B] color characteristic on a custom 128-bit service. Pick a color and the glowing bulb reacts — and a connected central is notified. Proof that any device, with any visual, is a few lines of Rhai.

Scanner observe

Joins your netsim scene as web-scanner and shows live decoded advertisements: names, RSSI, service UUIDs, manufacturer data. Spins up a few built-in demo advertisers so it shows something on a bare netsimd.

Scripted device showcase

A running SimBLE whose device is an editable Rhai script (defaults to a thermometer with a beating-heart view when it's a heart-rate monitor). Edit, press Run, and the device on the air changes. Generate any device with AI.

Crate documentation reference

Full API reference — every module, profile, and packet type, generated by cargo doc.

Every page needs a local netsimd (Android emulator canary channel) started with --ws-port 7681; each page shows the exact command when it can't connect (the Playground and Explorer also build devices offline). Best demo: open the Playground and the Scanner side by side against one netsimd, edit the device, press Run, and watch the scanner update. Source: github.com/schilit/simble.
