Simble in the browser

Simble's Rust Bluetooth stack compiled to WebAssembly, connected to the netsim daemon running on your machine — no backend, no interpreter.

Scanner

Joins your netsim scene as web-scanner and shows live decoded advertisements: names, RSSI, service UUIDs, manufacturer data. Spins up a few built-in demo advertisers so it shows something on a bare netsimd.

Scripted device

A running Simble whose device is defined by an editable Rhai script — edit it, press Run, and the device on the air changes. The live viewer renders whatever GATT structure the script builds (defaults to a thermometer); generate any device with AI.

Both pages need a local netsimd (Android emulator canary channel) started with --ws-port 7681; each page shows the exact commands when it can't connect. Best demo: open both pages side by side against one netsimd, edit the device in the scripted-device script, press Run, and watch the scanner update. Source: github.com/schilit/simble.
