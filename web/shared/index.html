SimBLE Shared Scene

One in-browser Link hosted in a SharedWorker — every same-origin tab joins the same radio scene. No netsim, no server. starting…

Try it: add a device below, then open this same page in a second tab and add a different device. Both tabs share one Link, so a scanner in one tab sees an advertiser added in the other, and a central connects to a peripheral from any tab. Your own devices are marked mine.
