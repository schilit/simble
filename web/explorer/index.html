Could not reach netsim at localhost:7681 — is netsimd running with its WebSocket frontend enabled? The API Explorer works fully offline: you can build and inspect a device without netsim. Connect to expose it on the scene. Start netsim with:

netsimd --logtostderr --no-shutdown --ws-port 7681

Needs the canary-channel emulator. Once connected, the device you assemble here advertises on the scene — open the scanner in another tab to see it.

Each Execute builds one Rhai statement from the form and evaluates it in the session's shared scope — the same engine the Playground runs as free text. Objects you create (a service, a characteristic) are let-bound (svc1, chr1, …) and become selectable inputs to later calls, so you build a device click by click. The page joins netsim as web-explorer when reachable.
