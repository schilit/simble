    The whole scene is hosted by one wasm Link in this tab. Adding or removing a device rebuilds the Link from an array of device specs — SimBLE's real GATT server, scanner, and central roles talking over the shared in-process medium. Peripherals advertise; centrals connect, exchange MTU and discover; scanners decode the advertisements — all the real Rust stack compiled to WebAssembly.
