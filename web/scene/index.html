Could not reach netsim at localhost:7681 — is netsimd running with its WebSocket frontend enabled? This page is served from the cloud, but the Bluetooth scene runs on your machine: each device in this tab connects to a local netsimd over ws://localhost:7681. Start it with:

netsimd --no-shutdown --ws-port 7681

In WebSocket mode the devices you add here join the Android emulator's scene, so the emulator app can scan, connect to, and discover these peripherals.

Adding or removing a device rebuilds the Link from an array of device specs — SimBLE's real GATT server, scanner, and central roles talking over the shared in-process medium. Peripherals advertise; centrals connect, exchange MTU and discover; scanners decode the advertisements — all the real Rust stack compiled to WebAssembly.
