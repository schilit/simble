This page is served from the cloud, but the Bluetooth scene runs on your machine: the wasm build of Simble in this tab connects to a local netsimd over ws://localhost:7681. Start it, and this page connects by itself:

# One-time: install the canary-channel emulator package (stable netsimd has no WebSocket endpoint)
~/Library/Android/sdk/cmdline-tools/latest/bin/sdkmanager --channel=3 emulator

# Start netsim with the WebSocket endpoint on
~/Library/Android/sdk/emulator/netsimd --logtostderr --no-shutdown --ws-port 7681 --test-beacons

Tip: open the scanner in a second tab — both tabs join the same netsim scene. Edit the script here, press Run, and watch the scanner tab pick up the change.
